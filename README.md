# Portafolio profesional — J. Benjamín Ossa

Portafolio web de Geografía, evaluación ambiental, permisos y análisis territorial para proyectos de energía e infraestructura.

## Sitio

- Página principal: [`index.html`](index.html)
- Sitio web previsto: https://benjamin-geo-o.github.io/portafolio-benjamin-ossa/
- Tecnologías: HTML, CSS y JavaScript, sin dependencias ni instalación.
- Las fotografías y cartografías están integradas directamente en `index.html` para evitar problemas de rutas de archivos al publicar.

## Cómo publicarlo en GitHub Pages

1. En este repositorio, abre **Settings → Pages**.
2. En **Build and deployment** selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Presiona **Save** y abre la URL del sitio cuando GitHub confirme el despliegue.

Los contenidos profesionales y referencias corresponden a la información compartida para este portafolio. La revisión final de atribuciones y documentos es responsabilidad del titular.
